<emu-clause id="sec-array.prototype.concat" type="built-in function">
        <h1>Array.prototype.concat ( ..._items_ )</h1>
        <p>This method returns an array containing the array elements of the object followed by the array elements of each argument.</p>
        <p>It performs the following steps when called:</p>
        <emu-alg>
          1. Let _obj_ be ? ToObject(*this* value).
          1. Let _array_ be ? ArraySpeciesCreate(_obj_, 0).
          1. Let _nextIndex_ be 0.
          1. Prepend _obj_ to _items_.
          1. For each element _item_ of _items_, do
            1. Let _spreadable_ be ? IsConcatSpreadable(_item_).
            1. If _spreadable_ is *true*, then
              1. Let _length_ be ? LengthOfArrayLike(_item_).
              1. If _nextIndex_ + _length_ > 2<sup>53</sup> - 1, throw a *TypeError* exception.
              1. Let _sourceIndex_ be 0.
              1. Repeat, while _sourceIndex_ &lt; _length_,
                1. Let _propertyKey_ be ! ToString(𝔽(_sourceIndex_)).
                1. Let _exists_ be ? HasProperty(_item_, _propertyKey_).
                1. If _exists_ is *true*, then
                  1. Let _subElement_ be ? Get(_item_, _propertyKey_).
                  1. Perform ? CreateDataPropertyOrThrow(_array_, ! ToString(𝔽(_nextIndex_)), _subElement_).
                1. Set _nextIndex_ to _nextIndex_ + 1.
                1. Set _sourceIndex_ to _sourceIndex_ + 1.
            1. Else,
              1. NOTE: _item_ is added as a single item rather than spread.
              1. If _nextIndex_ ≥ 2<sup>53</sup> - 1, throw a *TypeError* exception.
              1. Perform ? CreateDataPropertyOrThrow(_array_, ! ToString(𝔽(_nextIndex_)), _item_).
              1. Set _nextIndex_ to _nextIndex_ + 1.
          1. [id="step-array-proto-concat-set-length"] Perform ? Set(_array_, *"length"*, 𝔽(_nextIndex_), *true*).
          1. Return _array_.
        </emu-alg>
        <p>The *"length"* property of this method is *1*<sub>𝔽</sub>.</p>
        <emu-note>
          <p>The explicit setting of the *"length"* property in step <emu-xref href="#step-array-proto-concat-set-length"></emu-xref> is intended to ensure the length is correct when the final non-empty element of _items_ has trailing holes or when _array_ is not a built-in Array.</p>
        </emu-note>
        <emu-note>
          <p>This method is intentionally generic; it does not require that its *this* value be an Array. Therefore it can be transferred to other kinds of objects for use as a method.</p>
        </emu-note>

        
      </emu-clause>
