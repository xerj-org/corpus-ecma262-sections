<emu-clause id="sec-object.preventextensions" type="built-in function">
        <h1>Object.preventExtensions ( _obj_ )</h1>
        <p>This function performs the following steps when called:</p>
        <emu-alg>
          1. If _obj_ is not an Object, return _obj_.
          1. Let _status_ be ? <emu-meta effects="user-code">_obj_.[[PreventExtensions]]()</emu-meta>.
          1. If _status_ is *false*, throw a *TypeError* exception.
          1. Return _obj_.
        </emu-alg>
      </emu-clause>
