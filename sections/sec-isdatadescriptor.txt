        <h1>
          IsDataDescriptor (
            _propertyDesc_: a Property Descriptor,
          ): a Boolean
        </h1>
        <dl class="header">
        </dl>
        <emu-alg>
          1. If _propertyDesc_ has a [[Value]] field, return *true*.
          1. If _propertyDesc_ has a [[Writable]] field, return *true*.
          1. Return *false*.
