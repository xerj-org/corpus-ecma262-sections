ECMA-262 > 9 Executable Code and Execution Contexts > 9.1 Environment Records > 9.1.1 The Environment Record Type Hierarchy > 9.1.1.3 Function Environment Records > 9.1.1.3.1 BindThisValue ( _envRecord_: a Function Environment Record, _value_: an ECMAScript language value, ): either a normal completion containing ~unused~ or a throw completion [id: sec-bindthisvalue]

<emu-clause id="sec-bindthisvalue" type="abstract operation">
          <h1>
            BindThisValue (
              _envRecord_: a Function Environment Record,
              _value_: an ECMAScript language value,
            ): either a normal completion containing ~unused~ or a throw completion
          </h1>
          <dl class="header">
            <dt>description</dt>
            <dd>It sets the _envRecord_.[[ThisValue]] and records that it has been initialized.</dd>
          </dl>
          <emu-alg>
            1. Assert: _envRecord_.[[ThisBindingStatus]] is not ~lexical~.
            1. If _envRecord_.[[ThisBindingStatus]] is ~initialized~, throw a *ReferenceError* exception.
            1. Set _envRecord_.[[ThisValue]] to _value_.
            1. Set _envRecord_.[[ThisBindingStatus]] to ~initialized~.
            1. Return ~unused~.
          </emu-alg>
        </emu-clause>
