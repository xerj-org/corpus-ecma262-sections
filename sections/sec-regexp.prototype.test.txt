<emu-clause id="sec-regexp.prototype.test" type="built-in function">
        <h1>RegExp.prototype.test ( _string_ )</h1>
        <p>This method performs the following steps when called:</p>
        <emu-alg>
          1. Let _regexp_ be the *this* value.
          1. If _regexp_ is not an Object, throw a *TypeError* exception.
          1. Set _string_ to ? ToString(_string_).
          1. Let _match_ be ? RegExpExec(_regexp_, _string_).
          1. If _match_ is *null*, return *false*.
          1. Return *true*.
        </emu-alg>
      </emu-clause>
