<emu-clause id="sec-get-regexp.prototype.unicodesets" type="built-in function">
        <h1>get RegExp.prototype.unicodeSets</h1>
        <p>`RegExp.prototype.unicodeSets` is an accessor property whose set accessor function is *undefined*. Its get accessor function performs the following steps when called:</p>
        <emu-alg>
          1. Let _regexp_ be the *this* value.
          1. Let _codeUnit_ be the code unit 0x0076 (LATIN SMALL LETTER V).
          1. Return ? RegExpHasFlag(_regexp_, _codeUnit_).
        </emu-alg>
      </emu-clause>
