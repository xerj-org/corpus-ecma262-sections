ECMA-262 > 25 Structured Data > 25.1 ArrayBuffer Objects > 25.1.3 Abstract Operations For ArrayBuffer Objects > 25.1.3.12 IsBigIntElementType ( _type_: a TypedArray element type, ): a Boolean [id: sec-isbigintelementtype]

<emu-clause id="sec-isbigintelementtype" type="abstract operation">
        <h1>
          IsBigIntElementType (
            _type_: a TypedArray element type,
          ): a Boolean
        </h1>
        <dl class="header">
          <dt>description</dt>
          <dd>It verifies if the argument _type_ is a BigInt TypedArray element type.</dd>
        </dl>
        <emu-alg>
          1. If _type_ is either ~biguint64~ or ~bigint64~, return *true*.
          1. Return *false*.
        </emu-alg>
      </emu-clause>
