<emu-clause oldids="sec-regexp.prototype-@@search" id="sec-regexp.prototype-%symbol.search%" type="built-in function">
        <h1>RegExp.prototype [ %Symbol.search% ] ( _string_ )</h1>
        <p>This method performs the following steps when called:</p>
        <emu-alg>
          1. Let _regexp_ be the *this* value.
          1. If _regexp_ is not an Object, throw a *TypeError* exception.
          1. Set _string_ to ? ToString(_string_).
          1. Let _previousLastIndex_ be ? Get(_regexp_, *"lastIndex"*).
          1. If _previousLastIndex_ is not *+0*<sub>𝔽</sub>, then
            1. Perform ? Set(_regexp_, *"lastIndex"*, *+0*<sub>𝔽</sub>, *true*).
          1. Let _result_ be ? RegExpExec(_regexp_, _string_).
          1. Let _currentLastIndex_ be ? Get(_regexp_, *"lastIndex"*).
          1. If SameValue(_currentLastIndex_, _previousLastIndex_) is *false*, then
            1. Perform ? Set(_regexp_, *"lastIndex"*, _previousLastIndex_, *true*).
          1. If _result_ is *null*, return *-1*<sub>𝔽</sub>.
          1. Return ? Get(_result_, *"index"*).
        </emu-alg>
        <p>The value of the *"name"* property of this method is *"[Symbol.search]"*.</p>
        <emu-note>
          <p>The *"lastIndex"* and *"global"* properties of this RegExp object are ignored when performing the search. The *"lastIndex"* property is left unchanged.</p>
        </emu-note>
      </emu-clause>
