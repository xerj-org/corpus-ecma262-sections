ECMA-262 > 25 Structured Data > 25.1 ArrayBuffer Objects > 25.1.3 Abstract Operations For ArrayBuffer Objects > 25.1.3.10 IsUnsignedElementType ( _type_: a TypedArray element type, ): a Boolean [id: sec-isunsignedelementtype]

<emu-clause id="sec-isunsignedelementtype" type="abstract operation">
        <h1>
          IsUnsignedElementType (
            _type_: a TypedArray element type,
          ): a Boolean
        </h1>
        <dl class="header">
          <dt>description</dt>
          <dd>It verifies if the argument _type_ is an unsigned TypedArray element type.</dd>
        </dl>
        <emu-alg>
          1. If _type_ is one of ~uint8~, ~uint8clamped~, ~uint16~, ~uint32~, or ~biguint64~, return *true*.
          1. Return *false*.
        </emu-alg>
      </emu-clause>
