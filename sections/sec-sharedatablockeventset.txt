<emu-clause id="sec-sharedatablockeventset" type="abstract operation">
      <h1>
        SharedDataBlockEventSet (
          _execution_: a candidate execution,
        ): a Set of Shared Data Block events
      </h1>
      <dl class="header">
      </dl>
      <emu-alg>
        1. Let _events_ be an empty Set.
        1. For each Memory event _event_ of EventSet(_execution_), do
          1. If _event_ is a Shared Data Block event, add _event_ to _events_.
        1. Return _events_.
      </emu-alg>
    </emu-clause>
