<emu-clause id="sec-object.prototype.__lookupGetter__" type="built-in function">
          <h1>Object.prototype.__lookupGetter__ ( _key_ )</h1>
          <p>This method performs the following steps when called:</p>
          <emu-alg>
            1. Let _obj_ be ? ToObject(*this* value).
            1. Let _propertyKey_ be ? ToPropertyKey(_key_).
            1. Repeat,
              1. Let _propertyDesc_ be ? <emu-meta effects="user-code">_obj_.[[GetOwnProperty]](_propertyKey_)</emu-meta>.
              1. If _propertyDesc_ is not *undefined*, then
                1. If IsAccessorDescriptor(_propertyDesc_) is *true*, return _propertyDesc_.[[Getter]].
                1. Return *undefined*.
              1. Set _obj_ to ? <emu-meta effects="user-code">_obj_.[[GetPrototypeOf]]()</emu-meta>.
              1. If _obj_ is *null*, return *undefined*.
          </emu-alg>
        </emu-clause>
