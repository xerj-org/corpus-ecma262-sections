<emu-clause id="sec-object.defineproperty" type="built-in function">
        <h1>Object.defineProperty ( _obj_, _key_, _attrs_ )</h1>
        <p>This function adds an own property and/or updates the attributes of an existing own property of an object.</p>
        <p>It performs the following steps when called:</p>
        <emu-alg>
          1. If _obj_ is not an Object, throw a *TypeError* exception.
          1. Let _propertyKey_ be ? ToPropertyKey(_key_).
          1. Let _propertyDesc_ be ? ToPropertyDescriptor(_attrs_).
          1. Perform ? DefinePropertyOrThrow(_obj_, _propertyKey_, _propertyDesc_).
          1. Return _obj_.
        </emu-alg>
      </emu-clause>
