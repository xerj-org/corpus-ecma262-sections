<emu-clause id="sec-declarative-environment-records-createimmutablebinding-n-s" type="concrete method">
          <h1>
            CreateImmutableBinding (
              _name_: a String,
              _strict_: a Boolean,
            ): a normal completion containing ~unused~
          </h1>
          <dl class="header">
            <dt>for</dt>
            <dd>a Declarative Environment Record _envRecord_</dd>

            <dt>description</dt>
            <dd>It creates a new immutable binding for the name _name_ that is uninitialized. A binding must not already exist in this Environment Record for _name_. If _strict_ is *true*, the new binding is marked as a strict binding.</dd>
          </dl>
          <emu-alg>
            1. Assert: _envRecord_ does not already have a binding for _name_.
            1. Create an immutable binding in _envRecord_ for _name_ and record that it is uninitialized. If _strict_ is *true*, record that the newly created binding is a strict binding.
            1. Return ~unused~.
          </emu-alg>
        </emu-clause>
