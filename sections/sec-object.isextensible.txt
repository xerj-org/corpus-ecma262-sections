<emu-clause id="sec-object.isextensible" type="built-in function">
        <h1>Object.isExtensible ( _obj_ )</h1>
        <p>This function performs the following steps when called:</p>
        <emu-alg>
          1. If _obj_ is not an Object, return *false*.
          1. Return ? IsExtensible(_obj_).
        </emu-alg>
      </emu-clause>
