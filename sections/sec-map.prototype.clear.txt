<emu-clause id="sec-map.prototype.clear" type="built-in function">
        <h1>Map.prototype.clear ( )</h1>
        <p>This method performs the following steps when called:</p>
        <emu-alg>
          1. Let _map_ be the *this* value.
          1. Perform ? RequireInternalSlot(_map_, [[MapData]]).
          1. For each Record { [[Key]], [[Value]] } _entry_ of _map_.[[MapData]], do
            1. Set _entry_.[[Key]] to ~empty~.
            1. Set _entry_.[[Value]] to ~empty~.
          1. Return *undefined*.
        </emu-alg>
        <emu-note>
          <p>The existing [[MapData]] List is preserved because there may be existing Map Iterator objects that are suspended midway through iterating over that List.</p>
        </emu-note>
      </emu-clause>
