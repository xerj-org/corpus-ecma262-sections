ECMA-262 > 16 ECMAScript Language: Scripts and Modules > 16.2 Modules > 16.2.1 Module Semantics > 16.2.1.3 ModuleRequest Records > 16.2.1.3.1 ModuleRequestsEqual ( _x_: a ModuleRequest Record or a LoadedModuleRequest Record, _y_: a ModuleRequest Record or a LoadedModuleRequest Record, ): a Boolean [id: sec-ModuleRequestsEqual]

<emu-clause id="sec-ModuleRequestsEqual" type="abstract operation">
          <h1>
            ModuleRequestsEqual (
              _x_: a ModuleRequest Record or a LoadedModuleRequest Record,
              _y_: a ModuleRequest Record or a LoadedModuleRequest Record,
            ): a Boolean
          </h1>
          <dl class="header">
            <dt>description</dt>
            <dd></dd>
          </dl>

          <emu-alg>
            1. If _x_.[[Specifier]] is not _y_.[[Specifier]], return *false*.
            1. Let _xAttrs_ be _x_.[[Attributes]].
            1. Let _yAttrs_ be _y_.[[Attributes]].
            1. Let _xAttrsCount_ be the number of elements in _xAttrs_.
            1. Let _yAttrsCount_ be the number of elements in _yAttrs_.
            1. If _xAttrsCount_ ≠ _yAttrsCount_, return *false*.
            1. For each ImportAttribute Record _xAttr_ of _xAttrs_, do
              1. If _yAttrs_ does not contain an ImportAttribute Record _yAttr_ such that _xAttr_.[[Key]] is _yAttr_.[[Key]] and _xAttr_.[[Value]] is _yAttr_.[[Value]], return *false*.
            1. Return *true*.
          </emu-alg>
        </emu-clause>
