ECMA-262 > 13 ECMAScript Language: Expressions > 13.2 Primary Expression > 13.2.8 Template Literals > 13.2.8.3 Static Semantics: TemplateString ( _templateToken_: a |NoSubstitutionTemplate| Parse Node, a |TemplateHead| Parse Node, a |TemplateMiddle| Parse Node, or a |TemplateTail| Parse Node, _escapes_: ~raw~ or ~cooked~, ): a String or *undefined* [id: sec-templatestring]

<emu-clause id="sec-templatestring" type="abstract operation">
        <h1>
          Static Semantics: TemplateString (
            _templateToken_: a |NoSubstitutionTemplate| Parse Node, a |TemplateHead| Parse Node, a |TemplateMiddle| Parse Node, or a |TemplateTail| Parse Node,
            _escapes_: ~raw~ or ~cooked~,
          ): a String or *undefined*
        </h1>
        <dl class="header">
        </dl>
        <emu-alg>
          1. If _escapes_ is ~raw~, return the TRV of _templateToken_.
          1. Return the TV of _templateToken_.
        </emu-alg>
        <emu-note>
          <p>This operation returns *undefined* if _escapes_ is ~raw~ and _templateToken_ contains a |NotEscapeSequence|. In all other cases, it returns a String.</p>
        </emu-note>
      </emu-clause>
