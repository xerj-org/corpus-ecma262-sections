<emu-clause id="sec-weakset.prototype.delete" type="built-in function">
        <h1>WeakSet.prototype.delete ( _value_ )</h1>
        <p>This method performs the following steps when called:</p>
        <emu-alg>
          1. Let _weakSet_ be the *this* value.
          1. Perform ? RequireInternalSlot(_weakSet_, [[WeakSetData]]).
          1. If CanBeHeldWeakly(_value_) is *false*, return *false*.
          1. For each element _entry_ of _weakSet_.[[WeakSetData]], do
            1. If _entry_ is not ~empty~ and SameValue(_entry_, _value_) is *true*, then
              1. Replace the element of _weakSet_.[[WeakSetData]] whose value is _entry_ with an element whose value is ~empty~.
              1. Return *true*.
          1. Return *false*.
        </emu-alg>
        <emu-note>
          <p>The value ~empty~ is used as a specification device to indicate that an entry has been deleted. Actual implementations may take other actions such as physically removing the entry from internal data structures.</p>
        </emu-note>
      </emu-clause>
