<emu-clause id="sec-boolean-constructor-boolean-value" type="built-in function">
        <h1>Boolean ( _value_ )</h1>
        <p>This function performs the following steps when called:</p>
        <emu-alg>
          1. Let _bool_ be ToBoolean(_value_).
          1. If NewTarget is *undefined*, return _bool_.
          1. Let _obj_ be ? OrdinaryCreateFromConstructor(NewTarget, *"%Boolean.prototype%"*, « [[BooleanData]] »).
          1. Set _obj_.[[BooleanData]] to _bool_.
          1. Return _obj_.
        </emu-alg>
      </emu-clause>
