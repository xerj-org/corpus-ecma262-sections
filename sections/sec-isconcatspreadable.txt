<emu-clause id="sec-isconcatspreadable" type="abstract operation">
          <h1>
            IsConcatSpreadable (
              _obj_: an ECMAScript language value,
            ): either a normal completion containing a Boolean or a throw completion
          </h1>
          <dl class="header">
          </dl>
          <emu-alg>
            1. If _obj_ is not an Object, return *false*.
            1. Let _spreadable_ be ? Get(_obj_, %Symbol.isConcatSpreadable%).
            1. If _spreadable_ is not *undefined*, return ToBoolean(_spreadable_).
            1. Return ? IsArray(_obj_).
          </emu-alg>
        </emu-clause>
