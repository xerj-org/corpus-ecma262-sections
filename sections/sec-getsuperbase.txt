<emu-clause id="sec-getsuperbase" type="abstract operation">
          <h1>
            GetSuperBase (
              _envRecord_: a Function Environment Record,
            ): an Object, *null*, or *undefined*
          </h1>
          <dl class="header">
            <dt>description</dt>
            <dd>It returns the object that is the base for `super` property accesses bound in _envRecord_. The value *undefined* indicates that such accesses will produce runtime errors.</dd>
          </dl>
          <emu-alg>
            1. Let _home_ be _envRecord_.[[FunctionObject]].[[HomeObject]].
            1. If _home_ is *undefined*, return *undefined*.
            1. Assert: _home_ is an ordinary object.
            1. Return ! _home_.[[GetPrototypeOf]]().
          </emu-alg>
        </emu-clause>
