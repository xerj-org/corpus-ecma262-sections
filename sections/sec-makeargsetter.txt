<emu-clause id="sec-makeargsetter" type="abstract operation">
          <h1>
            MakeArgSetter (
              _name_: a String,
              _envRecord_: an Environment Record,
            ): a function object
          </h1>
          <dl class="header">
            <dt>description</dt>
            <dd>It creates a built-in function object that when executed sets the value bound for _name_ in _envRecord_.</dd>
          </dl>
          <emu-alg>
            1. Let _setterClosure_ be a new Abstract Closure with parameters (_value_) that captures _name_ and _envRecord_ and performs the following steps when called:
              1. Return NormalCompletion(! _envRecord_.SetMutableBinding(_name_, _value_, *false*)).
            1. Let _setter_ be CreateBuiltinFunction(_setterClosure_, 1, *""*, « »).
            1. NOTE: _setter_ is never directly accessible to ECMAScript code.
            1. Return _setter_.
          </emu-alg>
        </emu-clause>
