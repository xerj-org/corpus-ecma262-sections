<emu-clause id="sec-numeric-types-number-unaryMinus" type="numeric method">
          <h1>
            Number::unaryMinus (
              _number_: a Number,
            ): a Number
          </h1>
          <dl class="header">
          </dl>
          <emu-alg>
            1. If _number_ is *NaN*, return *NaN*.
            1. Return the negation of _number_; that is, compute a Number with the same magnitude but opposite sign.
          </emu-alg>
        </emu-clause>
