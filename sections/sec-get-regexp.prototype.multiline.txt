<emu-clause id="sec-get-regexp.prototype.multiline" type="built-in function">
        <h1>get RegExp.prototype.multiline</h1>
        <p>`RegExp.prototype.multiline` is an accessor property whose set accessor function is *undefined*. Its get accessor function performs the following steps when called:</p>
        <emu-alg>
          1. Let _regexp_ be the *this* value.
          1. Let _codeUnit_ be the code unit 0x006D (LATIN SMALL LETTER M).
          1. Return ? RegExpHasFlag(_regexp_, _codeUnit_).
        </emu-alg>
      </emu-clause>
