<emu-clause id="sec-object.values" type="built-in function">
        <h1>Object.values ( _obj_ )</h1>
        <p>This function performs the following steps when called:</p>
        <emu-alg>
          1. Let _coerced_ be ? ToObject(_obj_).
          1. Let _valueList_ be ? EnumerableOwnProperties(_coerced_, ~value~).
          1. Return CreateArrayFromList(_valueList_).
        </emu-alg>
      </emu-clause>
