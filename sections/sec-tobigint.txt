ECMA-262 > 7 Abstract Operations > 7.1 Type Conversion > 7.1.15 ToBigInt ( _arg_: an ECMAScript language value, ): either a normal completion containing a BigInt or a throw completion [id: sec-tobigint]

<emu-clause id="sec-tobigint" type="abstract operation">
      <h1>
        ToBigInt (
          _arg_: an ECMAScript language value,
        ): either a normal completion containing a BigInt or a throw completion
      </h1>
      <dl class="header">
        <dt>description</dt>
        <dd>It converts _arg_ to a BigInt value, or throws if an implicit conversion from Number would be required.</dd>
      </dl>
      <emu-alg>
        1. Let _primitive_ be ? ToPrimitive(_arg_, ~number~).
        1. Return the value that _primitive_ corresponds to in <emu-xref href="#table-tobigint"></emu-xref>.
      </emu-alg>
      <emu-table id="table-tobigint" caption="BigInt Conversions">
        <table>
          <thead>
            <tr>
              <th>
                Argument Type
              </th>
              <th>
                Result
              </th>
            </tr>
          </thead>
          <tr>
            <td>
              Undefined
            </td>
            <td>
              Throw a *TypeError* exception.
            </td>
          </tr>
          <tr>
            <td>
              Null
            </td>
            <td>
              Throw a *TypeError* exception.
            </td>
          </tr>
          <tr>
            <td>
              Boolean
            </td>
            <td>
              Return `1n` if _primitive_ is *true* and `0n` if _primitive_ is *false*.
            </td>
          </tr>
          <tr>
            <td>
              BigInt
            </td>
            <td>
              Return _primitive_.
            </td>
          </tr>
          <tr>
            <td>
              Number
            </td>
            <td>
              Throw a *TypeError* exception.
            </td>
          </tr>
          <tr>
            <td>
              String
            </td>
            <td>
              <emu-alg>
                1. Let _n_ be StringToBigInt(_primitive_).
                1. If _n_ is *undefined*, throw a *SyntaxError* exception.
                1. Return _n_.
              </emu-alg>
            </td>
          </tr>
          <tr>
            <td>
              Symbol
            </td>
            <td>
              Throw a *TypeError* exception.
            </td>
          </tr>
        </table>
      </emu-table>
    </emu-clause>
