<emu-clause id="sec-get-sharedarraybuffer.prototype.growable" type="built-in function">
        <h1>get SharedArrayBuffer.prototype.growable</h1>
        <p>`SharedArrayBuffer.prototype.growable` is an accessor property whose set accessor function is *undefined*. Its get accessor function performs the following steps when called:</p>
        <emu-alg>
          1. Let _obj_ be the *this* value.
          1. Perform ? RequireInternalSlot(_obj_, [[ArrayBufferData]]).
          1. If IsSharedArrayBuffer(_obj_) is *false*, throw a *TypeError* exception.
          1. If IsFixedLengthArrayBuffer(_obj_) is *false*, return *true*.
          1. Return *false*.
        </emu-alg>
      </emu-clause>
